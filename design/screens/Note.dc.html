Git: полезные команды

Разработка · изменена 18 сентября

Переписать историю

Склеить последние коммиты перед пушем в feature-ветку:

git rebase -i HEAD~3
git push --force-with-lease

Уборка

  • Удалить ветки, которых нет на remote: git fetch -p
  • Посмотреть, что уже слито: git branch --merged
  • Никогда не делать force-push в main.
